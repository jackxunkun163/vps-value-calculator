# VPS 剩余价值计算器 · 使用说明

> 在线页面与 [vps.ss](https://vps.ss/) 一致。全部计算在浏览器内实时完成，输入不会上传保存。

## 2. 快速上手（四步）

1. **① 续费信息**：输入商家标注的续费价格（如 `30`），选择计价币种（USD）和付款周期（年付）
2. **② 时间信息**：交易日期默认今天；到期日期已按周期自动推算，可点日历修改
3. **③ 交易结算**：填写你实际付给卖家的金额（如 `150`），溢价自动反推
4. 看右侧结果面板：**剩余价值、溢价/折价、买家总支出**一目了然；需要时再补 Push 费和中介担保

输入任意内容结果都会**实时重算**，无需点按钮。

## 3. 各功能区详解

### ① 续费信息

| 控件 | 说明 |
| :-- | :-- |
| 续费金额 | 商家的**续费价**（不是你实付的价），支持小数 |
| 计价币种 | USD / CNY / EUR / GBP / JPY / HKD / TWD / CAD 共 8 种 |
| 自定义 | 勾选后手动填汇率（如按支付宝/PayPal 实际结算价）；选 CNY 时该选项自动隐藏 |
| 付款周期 | 月付(30天) / 季付(91) / 半年(182) / 年付(365) / 两年(730) / 三年(1095) |

> **周期切换技巧**：点击周期按钮时，到期日期会自动重置为「交易日期 + 周期天数」，再手动微调即可。

### ② 时间信息

- **交易日期**：默认今天；点输入框弹出日历选择，也可直接键入 `YYYY-MM-DD`
- **到期日期**：机器的到期日（商家面板里能看到）
- **精确到时分**：右上角开关，适合短周期机器按小时折算（剩余天数会显示小数）
- 交易日晚于到期日时提示「已到期」，结果区清空

### ③ 交易结算

**实付卖家 / 卖家溢价 —— 双向反推**（两个输入框互算，点谁锁定谁）：

- 聚焦（点击）**实付卖家**框 → 锁定「由实付推算溢价」，溢价框自动填结果
- 聚焦**卖家溢价**框 → 锁定「由溢价推算实付」，实付框自动填结果
- 当前锁定方向显示在下方提示条 🔒

**Push 费**（转户手续费，可留空）：

- 金额 + 币种（11 种，含 KRW/SGD/AUD）+ 承担方（买家付 / 卖家付 / AA平摊）
- 按所选币种汇率折算成 CNY 计入对应方的支出

### ④ 实时汇率面板

- 服务端每小时从公开汇率接口拉取并缓存；页面打开时前端自动请求最新值并重算
- 当前计价币种所在格子高亮显示
- 角标显示「日期 已更新」；接口异常时显示警告并使用备用汇率

## 4. 结果面板解读

| 项目 | 含义 |
| :-- | :-- |
| **剩余价值 (CNY)** | 大字主结果 = 续费金额 ÷ 周期天数 × 剩余天数 × 汇率 |
| 卖家溢价 / 卖家折价 | 实付 − 剩余价值 − 卖家承担的 Push/中介费；正数溢价（绿色），负数折价 |
| 折合原币 | 剩余价值按计价币种显示（如 18.81 USD） |
| 官方日均 | 剩余价值 ÷ 剩余天数（纯价值口径） |
| **综合日均** | 买家总支出 ÷ 剩余天数（含溢价与全部费用，真实成本口径） |
| 剩余有效期 | 进度条 = 剩余天数 ÷ 周期天数 |
| 价值构成比例 | 剩余价值 vs 溢价部分的占比条 |
| 中介担保 (5%) | 勾选开启；承担方三选：买家付中介 / 卖家付中介 / AA平摊中介 |
| **买家最终总支出** | 实付 + 买家承担的 Push 费 + 买家中介费 |

## 6. 计算公式与完整示例

```
剩余价值 = 续费金额 ÷ 付款周期天数 × 剩余天数 × 汇率
溢价     = (实付 − 卖家Push分摊 − 卖家中介分摊) − 剩余价值
中介费   = 实付 × 5%
买家总支出 = 实付 + 买家Push分摊 + 买家中介分摊
综合日均  = 买家总支出 ÷ 剩余天数
```

**实测示例**（年付 30 USD，交易 2026-10-19，到期 2027-06-05，剩 229 天，汇率 1 USD = 6.683 CNY）：

| 输入 | 值 |
| :-- | :-- |
| 续费金额 / 周期 | 30 USD · 年付 |
| 实付卖家 | ¥150.00 |
| Push 费 | 8 USD · AA平摊 |
| 中介担保 | 开启 · 买家付中介 |

| 输出 | 值 |
| :-- | :-- |
| 剩余价值 | **¥125.79**（≈ 18.82 USD） |
| 卖家折价 | **−¥2.52**（150 − 26.73 Push半摊 − 125.79） |
| 官方日均 / 综合日均 | ¥0.549 / 天 · ¥0.805 / 天 |
| 中介费 (5%) | ¥7.50（买家承担） |
| **买家最终总支出** | **¥184.23** = 150 + 26.73 + 7.50 |

## 7. 数据与隐私

- 金额、日期等输入**只在浏览器与本次请求中使用**，不落库、不上报
- 常用配置（金额、币种、周期、中介设置）存在浏览器 `localStorage`，下次打开自动恢复；「重置」即清除
- 「分享图片」生成的 SVG 保存在服务器 `html/share/` 目录（Docker 卷 `vps-share`），用于长期访问的图片链接
- 计数（今日/累计）只存数字，不含任何输入内容

## 8. 常见问题

**Q：溢价是坏东西吗？**
不一定。可续费的低价年付、稀缺 IP、CN2 GIA/9929 等特殊线路都有附加价值，正溢价正常；接近到期或有跑路风险的机器折价也常见。

**Q：汇率和我实际结算的不一样？**
页面汇率来自公开接口（约每日更新一次，每小时拉取缓存）。与对方约定了其他结算价时，勾选「① 续费信息 → 自定义」填入你的汇率，立即重算。

**Q：两个金额框互相覆盖怎么办？**
这是「双向反推」设计：最后点击（聚焦）的那个框是输入方，另一个是结果。看 🔒 提示条确认当前方向。

**Q：分享链接太长？**
链接携带全部参数（含日期与金额），长是正常的；发论坛推荐用「分享图片」的 Markdown 代码。
